# Breakdown vs Preventive Maintenance Dashboard

A Power BI maintenance analytics dashboard designed to analyze equipment breakdowns, preventive maintenance activity, downtime, maintenance costs, and key maintenance performance indicators.

## Dashboard Preview

![Breakdown vs Preventive Maintenance Dashboard](Breakdown%20vs%20Preventive%20Maintenance%20Dashboard_Image.jpg)

## Project Overview

This dashboard provides an interactive view of maintenance performance by comparing breakdown activity with preventive maintenance and analyzing equipment-level downtime and maintenance trends.

## Key KPIs

| KPI | Value |
|---|---:|
| Maintenance Cost | $138.2K |
| Breakdown Count | 357 |
| Preventive Count | 631 |
| MTBF | 268.50 Hours |
| MTTR | 3.10 Hours |
| Avg PM Compliance | 85% |

## Analysis Covered

- Breakdown vs Preventive Maintenance Ratio
- Preventive Maintenance Compliance
- Planned vs Unplanned Downtime
- Downtime by Equipment Category
- Breakdown by Machine Age Group
- Maintenance Cost by Day
- Preventive Maintenance Count by Day
- Downtime by Failure Type
- MTBF and MTTR Analysis
